# ScenePad

Scene scripts and a teleprompter dock for OBS Studio on Windows and Apple silicon Macs.

- **Scene scripts:** Separate JSON files for each scene, with autosave and up to 200,000 characters per script.
- **Rich text:** Fonts, colors, strikethrough and paragraph formatting in the dock and browser.
- **Format painter:** Select source text, click the brush, then select a target. Double-click the brush on desktop to keep painting; click again or press Esc to exit.
- **Auto-scroll:** 0.1x to 5.0x, with a default of 0.5x. At 1.0x, text moves 10 pixels per second. Includes a countdown and reading guide.
- **Smooth scrolling:** Desktop wheel and arrow keys adjust the position without stopping playback; navigation jumps directly.
- **Reading progress:** Line numbers, total and selected character counts, scroll progress and saved reading positions.
- **Search and navigation:** Highlighted search and inline jumps by line or percentage.
- **Marks:** Orange marks with inline notes, quick deletion and navigation. Automatic mark lookup stops when editing resumes.
- **Return position:** In the dock, return to the reading position saved before navigation. The top-right arrow hides after returning, editing or switching scenes.
- **File transfer:** Import Word, HTML and text; export HTML or TXT.
- **Backup and clearing:** Back up the current script to JSON or all scenes to ZIP, with optional scheduled clearing.
- **Browser access:** LAN editing, remote control and independent reading, with app shortcuts on supported desktop and mobile browsers.
- **Mouse controls:** Alt-click toggles the dock lock. Alt-Shift-click inserts a mark in the dock or desktop browser; use Option on Mac.
- **Interface:** Theme-aware controls, customizable OBS hotkeys and English, Simplified Chinese and Traditional Chinese translations.
